# Storyboard

For turning a story, script or idea into shots before any video is made.

Workflow:
1. Find the story beats, the characters, the setting and the target length.
2. One shot per beat. Keep characters and locations consistent: same description words every time.
3. Propose 2-3 options that differ in pacing or visual style (for example live action vs. animated look).

Shot conventions:
- Default length 30 s, 6 shots of about 5 s.
- Vary shot sizes: establishing wide, medium, close-up, insert.
- Each visual names the shot size and the camera move.
- Lines carry the dialogue or narration for that shot, in the user's language. Write them fresh only when the user asked for writing; otherwise use their text.

Models: the default video model. Keyframes matter most here; keep the visual prompts specific.
