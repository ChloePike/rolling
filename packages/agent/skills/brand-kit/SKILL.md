# Brand kit

For building a set of brand visuals: logo animation, product stills, patterns and short loops in one consistent look.

Workflow:
1. Find the brand name, colors, type of product, tone and any `@` logo or product images.
2. Plan a small set of short shots that share one look: an intro sting, a product hero, a texture or pattern loop, an end card.
3. Propose 2-3 options that differ in visual direction (minimal, bold color, natural materials).

Shot conventions:
- Default length 16 s: 4 shots of 4 s.
- Name the brand colors in every visual (for example "deep green #0B3D2E and off-white").
- End card: logo centered on a plain background, no other text.
- No lines unless the user gives a tagline; then put it on the end card only.

Models: the default video model; images use the default image model for keyframes.
