品牌方案 · 第一轮

三个命名方向

每个方向都配了标志、字标、品牌色和在产品里的样子。三个标志都是纯几何，没有渐变，缩到 16 像素也能认。名字和域名、商标都还没查重。

方向 A · 温和、C 端友好
片刻Takes

「片」是影片，「刻」是一个瞬间，也是雕刻。英文 Takes 是片场里的「一条」，每次生成就是一条 take。

标志抽象场记板：上面一根斜杆，下面是画面
调性轻松、有温度，适合 C 端创作者和短视频用户
风险场记板意象在视频工具里比较常见，辨识度要靠颜色和字标撑

方向 B · 动作感、行动号召
开拍Rolling

导演喊「开拍」，机器开始转（Rolling）。名字本身就是一个动作，和「生成 / 执行整图」按钮的意思一致。

标志一颗实心圆，右上角挖出一个高光点，像录制灯，也像镜头
调性果断、专业，B 端和 C 端都能理解，中文好记好念

方向 C · 工具感、偏 B 端
织帧Weft

Weft 是织布时的纬线。画布上的节点、镜头、素材像经纬一样织在一起，最后成一条片子。

我的推荐
开拍 Rolling

中文两个字、人人会念，B 端客户和 C 端创作者都不需要解释；名字就是动作，主按钮、空状态、启动页都能直接用这个词。标志是一个圆，缩小、单色、做头像框都不会坏。

代价：报错状态要从纯红改成浅红 #F87171 加图标和文字，品牌橙红只出现在标志、启动页和营销物料里。

母品牌的粉色要不要继承
#FF3BA5 · AIGC.HUB

建议不继承。界面已经用了蓝色做强调，再加一个高饱和粉，两个强色会互相抢；粉色也会把产品往美妆、二次元方向带，和「B 端也能用」的定位有点冲突。

和母品牌的关系用文字背书：登录页、页脚、关于页写「by AIGC.HUB」，母品牌的粉色只留在它自己的标志里。
